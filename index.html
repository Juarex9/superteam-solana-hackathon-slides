01 · Solana

¿Qué es Solana?

Una infraestructura pública programable: una blockchain abierta (capa 1) cuyo token nativo es SOL.

MOVER VALOR

Pagos, stablecoins como USDC y settlement entre usuarios, empresas y agentes de IA.

REGISTRAR PROPIEDAD

Información verificable: tokens, activos digitales, credenciales y membresías.

LÓGICA ONCHAIN

Reglas que se ejecutan “en cadena” mediante programas, sin depender de un intermediario.

Tu app = frontend + backend + APIs + base de datos + una parte onchain cuando eso mejora realmente el producto.
02 · Conceptos clave

¿Por qué Solana?

~400 ms
POR BLOQUE

Cada “slot” dura ~400 ms: las transacciones se confirman casi al instante.

< US$0,01
POR TRANSACCIÓN

Fee base de 5.000 lamports por firma. Ideal para pagos y micropagos.

PoS + PoH
CONSENSO

Proof of Stake asegura la red; Proof of History es un “reloj” que ordena eventos.

SOL
TOKEN NATIVO

Paga las fees y se usa para staking. 1 SOL = 10⁹ lamports.

  • Rápida y barata = experiencias que se sienten como una app normal: el usuario no espera ni paga de más por usar blockchain.
03 · Bajo el capó

Cómo funciona

CUENTAS

Todo es una cuenta: guarda datos y SOL. Cada cuenta tiene un programa “dueño”.

PROGRAMAS

El código onchain (smart contracts). Sin estado propio: leen y escriben cuentas.

TRANSACCIONES

Una o más instrucciones firmadas por una wallet. Todo o nada (atómicas).

TOKENS SPL

El estándar de tokens: stablecoins como USDC, NFTs, puntos, membresías.

WALLETS

Phantom, Solflare y otras: guardan tus claves y firman transacciones.

REDES

Devnet para probar (SOL de prueba gratis). Mainnet para producción.

Programás en Rust (con Anchor) y armás el cliente en TypeScript.

11 · Herramientas para construir

Stack Solana

Según tu nivel

SOLANA PLAYGROUND

En el navegador: escribí, desplegá y probá programas sin instalar nada. Ideal para arrancar.

SETUP LOCAL (INSTALADOR OFICIAL)

Rust, Solana CLI, Anchor CLI, Surfpool, Node.js y Yarn. macOS, Linux o Windows vía WSL.

SOLANA DEV SKILL / MCP

Contexto actualizado de Solana para tu agente:
npx skills add solana-foundation/solana-dev-skill

Complementos útiles
  • Anchor · framework en Rust para programas
  • @solana/kit · SDK JS/TS (sucesor de web3.js)
  • Wallet Adapter · conectar Phantom, Solflare…
  • create-solana-dapp · scaffold de una dApp
  • RPCs · endpoint público de devnet o proveedores como Helius
  • Faucet · SOL de prueba en faucet.solana.com
Arrancá por el Quick Start oficial: solana.com/docs/intro/quick-start  ·  Siempre en devnet.
